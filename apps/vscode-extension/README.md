# Agent Remote for VS Code

Universal Open-Source Coding Agent Remote Control.

## Features

- 📡 **Universal Remote Bridge:** Connect your mobile phone or web browser directly to your VS Code workstation via 6-digit secure PIN pairing.
- ⚡ **Multi-Provider AI Intelligence:** Compatible with Google Gemini, Groq, OpenRouter, GitHub Models, Ollama, and TrueForge.
- 🛡️ **Interactive Approvals:** Approve or deny terminal commands and file edits right from your phone or the VS Code sidebar.
- 🔍 **Live Diff Streaming:** View live uncommitted Git diffs and stream model thoughts in real-time.
- 🐙 **One-Click PR & Issue Loading:** Import GitHub issues and draft full PRs directly from the session.

## Quick Start

1. Install the **Agent Remote** extension from the VS Code Marketplace.
2. Click the **📡 Agent Remote** icon in your Activity Bar.
3. Open `https://agent-remote.dev/pair` on your phone or web browser and enter the 6-digit PIN shown in the sidebar or Status Bar!
